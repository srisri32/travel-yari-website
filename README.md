# ✈️ Travel Yari – Travel & Tourism Website

Travel Yari is a responsive **Travel & Tourism website** designed to showcase beautiful destinations and provide users with a simple and attractive travel browsing experience.
The website includes a modern navigation bar, image carousel, destination cards, photo gallery, search section, social media section, and contact form.

## 🌍 Features

* 🏠 **Home Section** – Attractive landing page with travel carousel
* 🔍 **Destination Search** – Search section for finding travel destinations
* 📍 **Popular Places** – Displays popular destinations such as:

  * Munnar, Kerala
  * Alappuzha, Kerala
  * Pondicherry
* 🖼️ **Image Carousel** – Multiple travel images with automatic sliding
* 📸 **Photo Gallery** – Gallery section with 12 travel images
* 📱 **Responsive Design** – Designed using Bootstrap grid classes
* 📩 **Contact Form** – Users can enter name, email, mobile number, destination and message
* 🌐 **Social Media Section** – Social media icons for Facebook, YouTube, Google and Twitter
* 🎨 **Modern UI** – Uses Bootstrap, MDB, Font Awesome and Bootstrap Icons

## 🛠️ Technologies Used

* HTML5
* CSS3
* Bootstrap
* MDB (Material Design for Bootstrap)
* Font Awesome
* Bootstrap Icons
* JavaScript
* jQuery

## 📸 Website Sections

### 🏠 Home

The homepage contains a navigation bar and an image carousel showcasing travel destinations.

### 🔎 Search Destination

Users can enter a destination in the search field to plan their journey.

### 📍 Popular Places

The website displays popular tourist destinations with images and descriptions.

### 📸 Photo Gallery

A dedicated gallery section displays travel photographs in a responsive grid layout.

### 📩 Contact Us

The contact section provides booking information and a form for users to enter their details and travel requirements.

## 🚀 How to Run

1. Clone this repository:

```bash
git clone https://github.com/your-username/travel-yari-website.git
```

2. Open the project folder.

3. Make sure all image files and CSS/JavaScript files are in their respective locations.

4. Open `index.html` in your web browser.

## 🎯 Project Objective

The main objective of Travel Yari is to create a visually appealing and responsive travel website that allows users to explore destinations, view travel images, search for destinations, and contact the travel service.
